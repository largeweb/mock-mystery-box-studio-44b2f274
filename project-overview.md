# Project Overview

Project Name: Mock Mystery Box Studio

Description: A web application that allows creators to design, preview, and *mock* manage their own custom mystery box subscriptions. This platform will simulate the creation process, from selecting item categories to setting prices and visualizing performance metrics.

Features:
*   Mystery Box Designer:
    *   Category Selection: Creators can choose from pre-defined item categories (e.g., apparel, gadgets, collectibles).
    *   Themed Boxes: Creators can design themed boxes (e.g., "Retro Gaming," "Cozy Winter").
    *   Pricing Configuration: Creators can set the price for their mystery box.
    *   Mock Item Selection: Creators add a preview image to show what items will look like in the mystery box.
*   Subscription Management (Mocked):
    *   Tiered Subscriptions: Creators can offer different subscription tiers (e.g., Basic, Premium, Deluxe).
    *   Subscriber List: A mocked list to see subscribers and preview activity.
*   Performance Dashboard (Mocked):
    *   Sales Tracking: Simulated sales data to show the popularity of boxes.
    *   Customer Reviews: Display mocked reviews and testimonials.
    *   Revenue Projection: A mockup that estimates potential earnings.

Technology Stack:
*   Cloudflare next-on-pages framework (NextJS) for the web application.
